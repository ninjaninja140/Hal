# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Development

This project uses [Yarn 4](https://yarnpkg.com/) as its package manager, pinned through the `packageManager` field and run via [Corepack](https://nodejs.org/api/corepack.html).

```sh
yarn install
yarn dev        # start the Vite dev server
yarn build      # type-check and build the frontend
yarn preview    # preview the production build
yarn tauri dev  # run the Tauri app in development
```
